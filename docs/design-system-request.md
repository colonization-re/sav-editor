# Web UI request status

The component request that used to live here has been fulfilled in Web UI and is included
in the vendored stylesheet. See [design-system-gaps.md](design-system-gaps.md) for the
current migration note.

New reusable styling requests should be filed against
[`colonization-re/web-ui`](https://github.com/colonization-re/web-ui) and kept out of
[web/app.css](../web/app.css) unless they are truly specific to this save editor.
